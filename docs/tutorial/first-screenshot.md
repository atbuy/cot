# Your first screenshot

This walkthrough uses the main features once: selecting, adjusting, annotating, redacting and copying. It assumes you have [installed cot and set a keybind](installation.md).

## Freeze the screen

Open something on your screen, such as a web page, and hover over a button so it changes appearance. Without moving the mouse, press your keybind.

The screen dims slightly and stops updating. You are now looking at a frozen picture, with the hover state still in it.

## Select an area

Move the mouse over a window. It lights up, with its size shown beside it. Now drag to draw a selection around the button instead.

While you drag, a [magnifier](../guide/selecting.md#the-magnifier) follows the cursor so you can place the edge exactly.

When you release the mouse, the selection stays on screen with eight handles, and the toolbar appears next to it.

## Adjust it

- Drag a handle or edge to resize.
- Drag inside the selection to move it.

## Annotate

Click the **Arrow** button in the toolbar, then drag inside the selection to draw an arrow. Hover over any button for half a second to see what it does.

Made a mistake? Press ++ctrl+z++.

## Redact

Click the **Black bar** button and drag over anything you want to hide. See [Redacting](../guide/redacting.md) for when to use it over blur and pixelate.

## Finish

Press ++enter++ to copy the result to the clipboard, or ++ctrl+s++ to save it to `~/Pictures/Screenshots`. cot closes afterwards.
