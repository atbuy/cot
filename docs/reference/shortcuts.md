# Keyboard and mouse

## Selecting

| Input                      | Action                                        |
| -------------------------- | --------------------------------------------- |
| Drag                       | Draws a selection                             |
| Click                      | Selects the highlighted window                |
| ++ctrl++ + click           | Selects the monitor under the cursor          |
| ++ctrl++ + drag            | Draws a selection, replacing any existing one |
| Drag a handle or edge      | Resizes the selection                         |
| Drag inside the selection  | Moves the selection                           |
| Drag outside the selection | Replaces the selection                        |

## Finishing

| Input       | Action                                                                         |
| ----------- | ------------------------------------------------------------------------------ |
| ++enter++   | Copies to the clipboard. While typing text, finishes the text instead          |
| ++ctrl+c++  | Copies to the clipboard                                                        |
| ++ctrl+s++  | Saves to the screenshots folder                                                |
| ++esc++     | Cancels. While typing text, discards the text. With settings open, closes them |
| Right-click | Cancels                                                                        |

With nothing selected, ++enter++, ++ctrl+c++ and ++ctrl+s++ take all monitors.

## Editing

| Input                          | Action                                       |
| ------------------------------ | -------------------------------------------- |
| ++ctrl+z++                     | Undo                                         |
| ++ctrl+y++ or ++ctrl+shift+z++ | Redo                                         |
| ++backspace++                  | Deletes the last character while typing text |

The ++ctrl++ shortcuts follow physical key positions, so they keep working on non-Latin keyboard layouts.

## Instant mode

If **After selecting** is set to **Copy right away**, releasing the mouse copies immediately. Hold ++shift++ as you release to open the editor instead. See [Settings](../guide/annotating.md#settings).
